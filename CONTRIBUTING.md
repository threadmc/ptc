# Contributing to PTC

Thank you for considering contributing!

## How to Contribute

- Fork the repository and create your branch from `main`.
- Write clear, concise commit messages.
- Add tests for new features or bug fixes.
- Run `go fmt ./...` before submitting.
- Open a pull request and describe your changes.

## Bug Reports

- Search existing issues before opening a new one.
- Include steps to reproduce, expected and actual behavior.

## Feature Requests

- Explain your use case and proposed solution.

## Code Style

- Follow idiomatic Go conventions.
- Keep functions small and focused.

## Questions

Open a [discussion](https://github.com/threadmc/ptc/discussions) or contact us via issues.
